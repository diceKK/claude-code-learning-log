# Claude Code 学習記録（2日間のポートフォリオ）

## 概要

Claude Code を 2026-11-04〜11-05 の2日間で学んだ過程と成果を、マスク済みのスクリーンショット15枚で紹介する1ページのサイトです。

HTML・CSS・JavaScript だけで作っています。ビルドは不要で、外部ライブラリ・外部フォント・アナリティクスは使っていません。このフォルダの中身をそのまま GitHub Pages で公開できます。

## ファイル構成

```
（リポジトリのルート）
├── index.html                 ページの骨組み（文言は直書きしない）
├── favicon.svg                アイコン
├── .nojekyll                  Jekyll 処理を止める空ファイル
├── README.md                  このファイル
├── .github/
│   └── workflows/
│       └── pages.yml          main への push で GitHub Pages に公開する
├── assets/
│   ├── css/
│   │   └── style.css          デザイントークンと全スタイル
│   └── js/
│       ├── data.js            掲載データ（文言・画像・並び順・注目事例）
│       └── main.js            描画・絞り込み・拡大表示・URL ハッシュ連動
└── images/                    マスク済みスクリーンショット15枚（*.png）
```

## 文言・画像を更新する

文言・画像・並び順・注目事例は `assets/js/data.js` だけを編集すれば変わります。`index.html` と `main.js` を書き換える必要はありません。

`works`（作品）の各項目：

| 項目 | 必須 | 内容 |
|---|---|---|
| id | 必須 | 画像ファイル名から拡張子を除いたもの（例 `08-seo`）。URL の `#work/<id>` に使う |
| file | 必須 | `images/` に置いた画像ファイル名（例 `08-seo.png`） |
| date | 必須 | `2026-11-05` の形式。画面には `11/05` と表示される |
| step | 必須 | `step-1`〜`step-6`（`steps` の id） |
| title | 必須 | カードと拡大表示のタイトル |
| alt | 必須 | 画像の代替テキスト |
| tags | 必須 | 使った機能のタグ（1〜3個の配列） |
| metric | 任意 | 数値の実績。注目事例カードと拡大表示に太字で出る |
| goal | 必須 | やりたかったこと |
| action | 必須 | やったこと |
| result | 必須 | 結果 |
| featured | 任意 | `true` にすると注目事例に出る |

作品を追加する手順：

1. 画像を `images/` に置く。
2. `data.js` の `works` に1件追加する。配列の順番がそのまま表示順になる。
3. `id` は画像ファイル名から拡張子を除いたものにする。

注目事例に出したい作品には `featured: true` を付けます（3件を想定）。

数字の帯（`stats`）は自動では数えません。作品やスキルの数が変わったら、`stats` の値を手で更新してください。絞り込みボタンの件数とタイムラインの画像は `works` から自動で数えます。

## ローカルで確認する

- `index.html` をダブルクリックしてブラウザで直接開く。
- または、このフォルダで次を実行し、ブラウザで `http://localhost:8000/` を開く。

```
python -m http.server 8000
```

確認が終わったら Ctrl+C でサーバーを止めます。

## GitHub Pages で公開する

この作業は人が行います（作成時の作業では git 操作・push・Pages の設定はしていません）。

1. GitHub で新しいリポジトリを作る。
2. このフォルダ（site/）の中身をリポジトリのルートに置き、main ブランチに push する。
3. リポジトリの Settings → Pages を開き、Source を「GitHub Actions」にする。
4. Actions タブで「Deploy to GitHub Pages」が完了したことを確認する。
5. `https://dicekk.github.io/<リポジトリ名>/` を開いて表示を確認する。

## 絶対 URL の差し替え

SNS などで共有したときの画像（og:image）と URL（og:url）は絶対 URL が必要なため、`index.html` ではコメントにしてあります。公開先が決まったら次の手順で有効にします。

1. `index.html` の `<head>` にある次の2行を探す。
   - `<!-- <meta property="og:image" content="https://dicekk.github.io/<リポジトリ名>/images/08-seo.png"> -->`
   - `<!-- <meta property="og:url" content="https://dicekk.github.io/<リポジトリ名>/"> -->`
2. 各行の先頭の `<!--` と末尾の `-->` を消す。
3. `<リポジトリ名>` を実際のリポジトリ名に置き換える。
4. push して、公開後のページで反映を確認する。
